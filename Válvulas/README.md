# Códigos correspondientes a la ESP32S3 que simula el control de las válvulas.

## Segundo escenario de integración. Aplicación secuencial de 3 sustancias a 9 muestras.

Archivos ``.ino`` con el código fuente que emplea la ESP32S3 encargada del control de las válvulas representadas con LEDs habiendo usado la plantilla ESP32-S3-IoTDeviceTemplate proporcionada.
